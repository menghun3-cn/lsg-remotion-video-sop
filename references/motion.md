# 动效

用 Remotion 的 `interpolate`、`spring`、`Easing`。所有区间 `extrapolateLeft/Right: 'clamp'`。帧界从 `theme.ts` 读，不在组件里写魔法数。

spring 默认：`{damping: 16, stiffness: 130, mass: 0.7}`。卡片可把 mass 降到 0.6。连线用 `damping: 18, stiffness: 120`。

## 常用动效

确认表的「动效」「特效」列只能用下面两张表里的名字。前 12 种是这两部成片已经用过的底子。后面是讲解片和宣传片里同样常见、这两部还没单独做成函数的手法。

开场镜例外：logo、吉祥物、品牌名、主标题、副标题可以各有入场。主标题用字符跳动，副标题用逐词上浮或晚一拍的字符跳动，吉祥物用飞行并带粒子拖尾。

其余镜一个主操，再加一种转场。架构图、原理图可以在主操之外加令牌拖尾。数字跳动和翻牌计数不要用在同一个数字上。镜头转场、叠化、色块过场、圆形揭露，一镜只选一种。主动作前可以加 4 帧反向的预备，主体停住后拖尾再晚 4 帧停。

填确认表之前，先对照下面的「按内容选动效」。内容里有的种类都要落到某一镜，相邻镜不要重复同一个主操。原理卡和宣传功能卡相邻两张不要用同一种入场。

## 按内容选动效

种类用确认表里已有的动效名，不要另起名字。一种内容对应一种主操；同一镜已经有主操时，光效、粒子拖尾、描边可以作为特效加上。

| 内容 | 优先动效 | 特效 |
| --- | --- | --- |
| 品牌名、主标题、口号 | 字符跳动 | 无 |
| 副标题、结论金句、原理短句 | 逐词上浮 | 字距展开只给章节小标 |
| 吉祥物、logo、令牌在飞 | logo 吉祥物逐项飞行 | 粒子拖尾 |
| 多条卖点、多条结论要依次看见 | 卡片逐渐展示（渐入：透明度 0→1，同时上浮或从右侧滑入） | 无 |
| 四张及以上并列卡片，需要收成一个印象 | 粒子散开收束里的收束再散开成扇。先逐张渐入槽位，再收到中心，再散成扇形并旋转 | 无 |
| 架构连线、流程图、下划线、回边 | 描边生长 | 无 |
| 功能图标第一次出现 | 图标描线 | 扫光可在描完后扫一次 |
| 标题或数字刚定格、文本池里的一段被点出 | 扫光 | 无 |
| 爆点、汇聚、片尾成标 | 粒子效果，或粒子汇集形成 logo | 无 |
| 大章节切换、从整图切到实机、从实机切回收束 | 镜头转场 | 不要再叠加色块过场或圆形揭露 |
| 许多节点里只讲一个 | 聚焦压暗 | 脉冲呼吸只给当前节点 |
| 实机点击、Tab、按钮 | 光标点击 | 波纹 |
| 有无对比、改前改后 | 分屏对比 | 无 |
| 上屏、落地、卡片砸上 | 挤压拉伸或弹性过冲 | 闪白只给命中的第一帧 |
| 卡片正面要翻到解释 | 三维翻转 | 无 |
| 占比、完成度、步骤走到第几步 | 环形进度或步骤条 | 数字跳动只在有真实终值时用 |
| 图上点一个细节 | 标注引出 | 折线用描边生长 |

原理讲解默认排法：开场用跳动和粒子拖尾；结论用逐词上浮；架构图用描边生长；原理图用标注引出或扫光；逐节点用聚焦压暗加粒子拖尾；原理卡用卡片渐入，四张及以上时收束成扇形；切到下一章用镜头转场；有按键或界面就用光标点击和波纹；收束用粒子汇集或圆形揭露。

产品宣传默认排法：开场用跳动和粒子拖尾；卖点卡渐入；卖点收成扇形；切到实机用镜头转场；实机用打字机、光标点击、波纹；有数字卖点用数字跳动后再扫光；图标用描边；收束用粒子汇集形成 logo，或字体跌倒。

内容里没有该项，就不要硬加。例如没有真实百分比就不用环形进度，没有点击就不用光标。总览用两行列出结果：

- 已用：本片落地的种类
- 未用：种类，以及缺的是哪类内容

| 动效 | 什么时候用 | 怎么做 | 范本 |
| --- | --- | --- | --- |
| 字符跳动 | 标题、口号、产品名 | 每个字 `translateY`，关键帧 15 帧内 `[40, -16, 5, 0]`，字与字错开 2 帧 | promo `hop` / `JumpText` |
| 卡片逐渐展示 | 功能卡、结论卡、原理卡 | 宣传：右外侧滑入，间隔 12 帧，16 帧到位；或 `translateY` 18→0、透明度 12 帧。架构：`spring` 上浮 22px，离场最后 12 帧透明度到 0 | promo `FeatureFan`、结论卡；hotpath `CardShell` |
| logo 吉祥物逐项飞行 | 开场标志、吉祥物、功能卡入列 | 标志先跳，吉祥物晚 22 帧再跳；卡片从画面外飞到各自槽位 | promo `Conclusion`、`FeatureFan` |
| 数字跳动 | 准确率、耗时、词数、权重 | `interpolate` 从 0 到终值，`Math.round` 或保留 1 位小数，时长 12–20 帧，不要每帧乱跳 | 确认表写明终值；范本公式卡是静态权重，新片要用跳动就把终值放进 theme |
| 图表动图 | 占比、耗时、排序分项 | 条宽或柱高从 0 涨到终值，18–24 帧，`Easing.out(Easing.cubic)`；坐标和终值先画静态再长 | hotpath 底边进度条是最简形式（宽度 0→1920 铺满全片） |
| 粒子效果 | 强调爆点、汇聚前的尘埃 | 64 个圆点，角度均匀，半径随 t 变，颜色只用纸底上的叶绿 | promo `Scatter` |
| 粒子拖尾 | 令牌、吉祥物、logo 在飞 | 沿同一路径取当前点之前 6–10 个采样，圆点半径递减、透明度递减，跟在飞行物后面 | hotpath `Token` 只有令牌；拖尾按令牌的 `u` 回采样 |
| 飞行弧线转向 | 热路径走完要回到核心、吉祥物绕行 | 三次贝塞尔，控制点向画面外侧拱出。范本回边：`M x1 y1 C bow y1, bow y2, x2 y2`，虚线 | hotpath `Connectors` 回边 |
| 镜头转场 | 宣传片切镜 | 重叠 12 帧。入：缩放 1.14→1、透明度 0→1。出：缩放 1→1.16、透明度 1→0 | promo `shotStyle`，`HALF = 12` |
| 粒子散开收束 | 功能卡集合、爆点 | 收束：各卡插值到画面中心堆叠。散开：从堆叠到扇形（水平错开，越靠边旋转越大，`transformOrigin` 在下方）。粒子散开是径向距离 0→最大，半径变小 | promo `FeatureFan` 的 gather/fan；`Scatter` |
| 字体跌倒 | 片尾一个字或 logo 字 | 绕底部原点旋转 0→88°，中间关键帧过冲 1.05 再回到 1 | promo `FallingYe` |
| 粒子汇集形成 logo | 开场或品牌收束 | `Scatter` 反过来：粒子从四周的最大半径插值到 logo 中心，到位后粒子透明度到 0，logo 用字符跳动或 spring 出现 | 新片按 Scatter 的角度公式，t 从 1 收到 0 |

## 行业常用（补充）

和前 12 种并列，确认表可以选。范本列写「新片」的，按表里的做法做，不要为了凑效果去改 hotpath / promo 的成片。

### 文字与数字

| 动效 | 什么时候用 | 怎么做 | 范本 |
| --- | --- | --- | --- |
| 打字机 | 输入框、命令、代码 | 按帧把字符串切片变长，末尾光标每 15 帧闪一次 | promo `typed` |
| 逐词上浮 | 副标题、金句 | 按词不按字，`translateY` 18→0、透明度 0→1，词间隔 4 帧 | 新片。标题仍用字符跳动 |
| 字距展开 | 片名字、章节小标 | `letterSpacing` 从 0.4em 收到目标字距，12–16 帧 | 新片 |
| 扫光 | 标题或数字定格之后 | 父级 `overflow: hidden`，一道斜向半透明渐变 `translateX` 扫过，10–14 帧，只扫一次 | 新片 |
| 翻牌计数 | 数字从旧值换成新值 | 上下两半 `rotateX`，过 90° 换字再转到 0。同一数字不要再加数字跳动 | 新片 |

### 图形生长

| 动效 | 什么时候用 | 怎么做 | 范本 |
| --- | --- | --- | --- |
| 描边生长 | 流程图、下划线、回边 | 线段终点按进度插值，或 SVG `strokeDashoffset` 从周长收到 0 | hotpath `Connectors` |
| 图标描线 | 功能图标第一次出现 | 图标改成描边路径，`strokeDashoffset` 画完再填色 | 新片 |
| 环形进度 | 占比、完成度 | 圆周长固定，`strokeDashoffset` 收到目标弧，18–24 帧，中间数字用数字跳动 | 新片 |
| 步骤条 | 多步流程走到第几步 | 已完成段宽度插值，当前圆点放大，未到的步保持灰色 | hotpath 底边进度条的分段版 |
| 标注引出 | 图上点一个细节 | 折线先描边生长，末端标签再 spring | 新片 |

### 镜头与转场

| 动效 | 什么时候用 | 怎么做 | 范本 |
| --- | --- | --- | --- |
| 叠化 | 同一背景上换一块信息 | 12 帧交叉透明度，不缩放 | 新片。宣传大切镜仍用镜头转场 |
| 遮罩擦除 | 标题、截图入画 | `clip-path: inset()` 从一侧收到 0，12–16 帧 | 新片 |
| 推拉摇移 | 实机长图、界面截图 | 缩放 1→1.08，或纵向 `translateY` 缓缓滚过，`Easing.inOut` | promo `Overview` 滚动 |
| 视差 | 底纹、卡片、前景字同时在 | 同一进度乘不同位移：背景 0.3、中景 1、前景 1.4 | 新片 |
| 色块过场 | 大章节切换 | 品牌色矩形横向铺满，铺满的那一帧切下一镜，再揭开，共 14–18 帧 | 新片 |
| 圆形揭露 | logo 或章节从中心打开 | `clip-path: circle()` 半径从 0 增到盖住画面 | 新片。和粒子汇集形成 logo 接在汇集之后 |
| 匹配剪辑 | 小元素飞到下一镜变成主体 | 两镜共用同一个中心点，前镜放大、后镜从同一尺寸收回 | 新片 |
| 闪白 | 上屏、命中、爆点 | 全屏白 6–8 帧，透明度 0→0.85→0，放在主动作的第一帧 | 新片 |
| 分屏对比 | 改前改后、在线/离线 | 竖线从一侧推到中线，左右各留一块画面 | 新片 |

### 强调与演示

| 动效 | 什么时候用 | 怎么做 | 范本 |
| --- | --- | --- | --- |
| 弹性过冲 | 徽章、按钮、CTA | 缩放 0.86→1.06→1，三关键帧约 12 帧 | 新片 |
| 挤压拉伸 | 吉祥物落地、卡片砸上 | `scaleX` 与 `scaleY` 互补：下落略拉长，落地压扁再回正 | 新片。可接在字体跌倒后面 |

## 架构片额外节奏（hotpath）

- 开场之后再进结论。架构图、原理图都在结论之后、逐节点之前，整图一起 `spring` 出现，不要一个节点一个节点长出来。
- 架构图的节点是模块，连线是调用。原理图的节点是机制步骤。两张都要时不要复用同一组坐标再改个标题。
- 逐节点阶段：当前节点全亮，其余透明度约 0.42。令牌从当前节点中心飞到下一节点中心，并带粒子拖尾。
- 原理卡盖住图时，把图的透明度降到约 0.35，不要卸掉，收束时再回来。每张卡的入场按确认表，不都用同一种 spring。
- 底边步骤条从架构图或原理图出现后按镜推进。

## 宣传片额外节奏（promo）

- 功能扇三拍：逐张飞入槽位 → 收到中心 → 散成扇形并旋转。三拍的帧界写在 theme：`FAN_IN`、`FAN_GATHER_AT`、`FAN_GATHER_END`、`FAN_SPREAD_END`。
- 实机段用复刻的界面组件（范本是候选窗）或 `staticFile` 截图。打字用字符串切片，不要 CSS 动画。
- 切镜用镜头转场，不要硬切，除非确认表写了硬切。
