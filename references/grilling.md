# 拷问

一轮内问完，格式：

```
❓ **Q1** - **<标题>**: <题干与选项>

➡️ <推荐>
```

用户已经在原话里定了的项不要再问。网站有哪些模块、代码里热路径经过哪些层，自己读仓库后再把候选清单拿给用户勾选。

## 分类 A — 架构原理知识讲解

范本：`videos/zhu-ye-hotpath`，开场对齐 `videos/zhu-ye-promo` 的 logo 与吉祥物，再对齐 `videos/zhu-ye-translation` 的品牌主副标题。结构：约 8 秒品牌开场，结论，架构图（涉及架构时），原理图，逐节点，原理卡每张换一种入场，收束。

开场不单问有无。默认 logo + 吉祥物 + 品牌名 + 主标题 + 副标题。吉祥物用产品已有形象；没有现成形象时才问用户描述，推荐沿用竹叶吉祥物或用户给过的那个。用户坚持不要吉祥物，才在总览写明去掉。

架构图和原理图不作为可选项。讲原理就有原理图。内容里有分层、模块或调用链，就再有架构图。

- **Q1 时长**（推荐 C，都已含 8 秒开场）
  - A 70s：开场 + 结论 + 一张图
  - B 95s：开场 + 结论 + 架构图或原理图 + 逐节点，原理卡压缩
  - C 120s（推荐）：开场、结论、架构图、原理图、逐节点、原理卡都留得住
- **Q2 讲解对象**（推荐：你从仓库提炼的一条热路径）
  - 先列出候选路径（入口 → 中间层 → 核心 → 回写），推荐其中一条完整按键/请求路径
  - 选项：采用推荐路径 / 用户改范围 / 只讲分层不走单次调用
- **Q3 开场结论条数**（推荐 3）
  - 1 条 / 3 条（推荐，范本是三条可检验结论）/ 5 条
- **Q4 是否逐节点**（推荐 A）
  - A 逐节点，每节点约 5 秒，当前节点亮、其余压暗，令牌沿边飞行（推荐）
  - B 只亮整张图，不单步
- **Q5 原理卡**（推荐 A）
  - A 要。每张约 7 秒，一张一个不变量，每张入场不同（推荐）
  - B 不要，逐节点后直接收束
- **Q6 字幕**（推荐 A）
  - A 底中胶囊，只在该句播出的帧内出现，字与旁白相同（推荐）
  - B 不要字幕，字只留在画面里
- **Q7 配色**（推荐 A）
  - A 沿用范本纸底 `#f7f9f4`、墨 `#22302a`、叶绿 `#3d7a4e`（推荐）
  - B 按目标产品取色
- **Q8 旁白气质**（推荐 A；引擎不在这里选）
  - A 讲解，沉稳（推荐；Edge 降级时用 `zh-CN-YunyangNeural`，rate `-4%`）
  - B 口播，轻快（Edge 降级时用 `zh-CN-XiaoxiaoNeural`，rate `-5%`）
- **Q9 音效**（推荐 B）
  - A 要：节点点亮、令牌飞行、卡片入场各一条短音效
  - B 不要，只要讲解（推荐，范本没有音效）

分辨率默认 1920×1080、30fps，不要另问，除非用户主动要竖屏或 720p。

## 分类 B — 产品宣传

范本：`videos/zhu-ye-promo`。约 75.3 秒，30fps，2258 帧。开场同样是 logo + 吉祥物 + 品牌 + 主标题 + 副标题，然后功能网格、八张卡飞入后收束再散开成扇、下载页、实机演示、结论卡、字跌倒收尾。功能卡入场不要四张同一个动作。

- **Q1 叙事**（推荐 A）
  - A 痛点或一句话钩子 → 功能巡礼 → 实机 → CTA（推荐）
  - B 纯功能巡礼
  - C 吉祥物/品牌故事为主线
  - D 数字见证（准确率、耗时、词库规模）
- **Q2 模块数量**（推荐 8，或网站实际核心模块数）
  - 4 / 6 / 8（推荐）/ 跟产品实际模块
  - 你先从首页或仓库列出候选模块名，请用户勾选
- **Q3 时长**（推荐 C）
  - A 45s 快闪 / B 60s / C 75s（推荐，对齐范本）/ D 90s
- **Q4 配色**（推荐 A）
  - A 沿用范本竹叶绿纸（推荐）
  - B 从产品首页取色
  - C 用户给色值
- **Q5 吉祥物形象**（只在没有现成形象，或有多个形象时问；推荐 B）
  - A 用户描述一个新形象 / B 产品已有吉祥物，开场跳入并在后面飞行（推荐）
  - 已有唯一形象就不要问，直接用
- **Q6 文案语言**（推荐中文）
  - 中文（推荐）/ 英文 / 中英双语
- **Q7 口号**（推荐 A）
  - A 你拟 2–3 条让用户挑（推荐）/ B 用户直接给
- **Q8 结尾 CTA**（推荐 A）
  - A 下载或访问（推荐，范本是下载页 + 系统范围）/ B 开始使用 / C 无 CTA，停在一句话
- **Q9 实机画面**（推荐 A）
  - A 嵌入真实界面截图或复刻候选窗（推荐）
  - B 纯图形，不出现产品界面
- **Q10 字幕**（推荐 A）
  - A 底中胶囊，跟随旁白同句（推荐）
  - B 不要字幕
- **Q11 旁白气质**（推荐 B）
  - A 讲解沉稳（Edge 降级 `zh-CN-YunyangNeural`，`-4%`）
  - B 宣传轻快（推荐；Edge 降级 `zh-CN-XiaoxiaoNeural`，`-5%`）
- **Q12 音效**（推荐 A）
  - A 要：卡片入场、扇形散开、粒子、CTA 各一条短音效（推荐）
  - B 不要

分辨率同样默认 1920×1080、30fps。
